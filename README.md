# Enny Event Space — Venue Booking Platform

**Live:** https://enny-event-space.vercel.app
**Stack:** React, TypeScript, Tailwind CSS, shadcn/ui, Vite, Supabase

A booking platform for event venues in Lagos — searchable by location, capacity, and price. Built to replace the Instagram/WhatsApp hunt.

**Features I built:**
- Venue listing grid with filters (React state)
- Venue details + image gallery (shadcn components)
- Booking validation (date, guest count)
- Fully responsive — tested on mobile
- Deployed on Vercel with CI from GitHub

**Run locally:**
npm i
npm run dev
